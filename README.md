# POS System (pos_EDU)

## 專案簡介
本專案為針對服飾零售與電商通路設計的智慧型銷售時點系統（POS）。系統核心旨在整合實體店面與線上商城的營運數據，提供雙軌庫存同步、彈性商品條碼管理、折讓處理及會計報表生成等功能，滿足現代零售業務的高效管理需求。

## 系統特點
* 支援跨平台多裝置瀏覽與操作，適應不同載具使用情境。
* 具備實體優先與線上同步的雙軌庫存管理架構。
* 支援動態條碼與價格維護，因應每年換季之編號調整需求。
* 內建單品與整單折讓模組，並自動產生相關會計記錄。

## 系統需求
* Python 3.10 或以上版本
* Flask 3.0.2
* 現代網頁瀏覽器（支援 Chrome、Safari、Edge、Firefox 等）
