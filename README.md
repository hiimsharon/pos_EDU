# 💎 AURA VOGUE | 現代高質感女裝電商與 POS 系統 (v1)

歡迎來到 AURA VOGUE 全通路智慧零售與女裝電商系統！本系統專為現代高質感服飾店設計，結合了前端奢華視覺與後端強大收銀、折讓與雙軌庫存管理。

## 🚀 專案版本紀錄
- **v1.0.0 (當前版本)**
  - 建立現代 Glassmorphism 3D 磨砂玻璃視覺介面。
  - 實作「實體優先、線上同步」的雙軌庫存管理。
  - 支援商品動態建檔與跨年度條碼修改。
  - 具備會員登入/註冊與管理員權限分離（家人傳送網址即看，管理員解鎖收銀/會計）。
  - 內建折讓功能與會計報表模組。
  - 新增智能穿搭試衣間微互動小工具。

## 🌐 專案架構
- **Frontend**: HTML5, CSS3 (Glassmorphism), JavaScript, Bootstrap 5
- **Backend / DB**: Python Flask, PostgreSQL 邏輯設計
- **Hosting**: Vercel / GitHub Pages (100% Free)
